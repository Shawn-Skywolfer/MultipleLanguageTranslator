文档翻译参数

发送前会自动压缩图片；如企业安全代理拦截图片上传，会自动切换为本地 OCR + 纯文本模型翻译。图片任务固定单并发并对 429 进行指数退避。Chrome / Edge 保存后会自动重读文件并验证字节、CRC 与包结构。
PPTX 会输出“原始页保留 + 每页后新增 1 页译文页”的翻译版 PPTX。普通文本框、表格单元格和图片文字都会纳入完整性检查；任何对象翻译失败时将阻止导出，避免生成漏译文件。导出前还会校验 OOXML、关系文件和幻灯片结构。

共享翻译规则与目标语言

这里的设置会同时应用到文档翻译和 CSV 批量翻译。

标准翻译库（可选）

尚未上传标准翻译库。支持窄表：source/source_text/原文 + target_lang/language + translation/target_text/标准译文；也支持宽表：source + German/French/Chinese 等语言列。

术语保护与自定义规则（可选）

命中源文时，要求译文保留完全一致的大小写、空格、连字符、型号和商标。
支持自由文本，会原样传入模型。
可选上传术语 CSV：优先读取 term/protected_term/术语/词条列；未找到时读取第一列非空值并追加到受保护术语。
